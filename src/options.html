AI Chat Downloader

Everything runs in your browser. No account, no server, no analytics. Conversations are read from the page you are already looking at and written straight to your downloads folder.

Default format

The format the popup starts on. Every export still lets you switch.

Sites

Turn a site off if you never export from it. Turning a site off does not reduce the permissions the extension holds; the browser grants those at install time.

Site status

A site shows as unverified until someone has run an export against a live signed-in conversation and recorded the date. An unverified site can still be wrong, because chat sites change their markup without notice.

Limits worth knowing

  • PDF uses the built-in PDF fonts, which cannot draw characters outside Latin-1. CJK text becomes question marks in PDF only; Markdown, text, and Word keep it.
  • Only messages the page has rendered can be read. A very long conversation may be partial until you scroll through it.
  • One conversation per export. There is no bulk or whole-history export.
